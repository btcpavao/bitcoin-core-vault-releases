## Compare your own build

On a disposable 64-bit amd64 Linux computer, install Git and Docker, clone the project and change into the repository. The [beginner's guide](../REBUILD.md) covers these steps. Download the candidate ISO from the release into the directory **next to** the repository under its published filename. Run this in Bash from the repository root:

```bash
(
  set -eu
  git switch --detach 71242344618ba499278ea2abe49d7343a7f9a1c4
  bash tools/rebuild/build.sh ../vault-native-result
  rebuilt=../vault-native-result/bitcoin-core-vault-amd64.iso
  published=../bitcoin-core-vault-native-rebuild-candidate-71242344618b-amd64.iso
  expected=2b8f8fd5225b4b2ccee1d8ccc6847c647cb6f5d2481fa2d9ef94820a13b09ddc
  printf '%s  %s\n' "$expected" "$rebuilt" "$expected" "$published" | sha256sum --check
  cmp -- "$rebuilt" "$published"
  echo 'Your rebuilt Vault ISO matches the downloaded candidate byte for byte.'
)
```

If your account uses `sudo docker`, use `bash tools/rebuild/build.sh --sudo-docker ../vault-native-result` on the build line. The complete source snapshot and corresponding C++ sources are available on the release. Official Debian packages, Bitcoin Core and KeePassXC remain externally supplied inputs with their own provenance; consult the [input discussion](../REBUILD.md#inputs-to-inspect) for details.
