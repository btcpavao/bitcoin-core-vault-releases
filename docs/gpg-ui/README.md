## Guide readability update — 16 October 2026

Guide body text is 14 pt (previously 10 pt), navigation and subtitle 13 pt, section headings 22 pt and subheadings 17 pt. Paragraphs use 150% line height. The navigation width and content spacing accommodate the larger text. All 18 sections were rendered offscreen at 1024×768 and 1366×768 without horizontal overflow; security and recovery screenshots were visually inspected. See `guide-typography-checks.json`. This is a source update for the next ISO; the current VM image predates it. Concept illustrations and the 1/2/3-layer demonstration are now implemented; see ../guide-visuals/README.md.
