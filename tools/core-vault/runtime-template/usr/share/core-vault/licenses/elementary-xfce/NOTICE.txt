elementary Xfce power icons

Unmodified source SVGs copied from Debian elementary-xfce-icon-theme 0.21-1,
theme elementary-xfce-hidpi, actions/48/system-reboot.svg and system-shutdown.svg.
These are the exact artwork resources used by the host XFCE actions panel.
The host renders the icons at 44 px; Bitcoin Core Vault uses the same size.
