# Bitcoin Core Offline Signer — RC1

Live-only, stateless Bitcoin Core signing environment.

## Properties

- Debian 13 Trixie base
- Bitcoin Core 31.1
- Live boot only
- `toram`
- no installer
- volatile Core datadir/session
- networking disabled
- removable-media PSBT/wallet workflow
- BIOS and UEFI VM tested
- physical ThinkPad T530 tested
- responsive branded boot/shutdown UI
